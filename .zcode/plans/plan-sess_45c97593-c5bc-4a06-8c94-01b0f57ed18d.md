# MusicFree → Apple Music 深色风格改造计划（含 Material 图标统一）

## Context

在不改变任何功能行为（播放/搜索/歌词/插件/导航路由）的前提下，将 MusicFree 移动端 UI 改造为 **Apple Music 深色风格**：黑色画布 #000000 + 深灰表面 #1C1C1E + 珊瑚红强调 #FA2D48 + 白色文本；并将全局图标统一为 **Material Design 图标**。执行 Step 0–5 + Step 7 回归（Step 6 其他页面暂不做）。

**用户确认的方向**：只改造深色主题，浅色主题（lightTheme）保持原样不动；图标统一为 Material Design。应用本就默认深色启动（`theme.ts:76`），默认值无需改动。

**关键事实**
- 主题唯一来源 `src/core/theme.ts`；字号在 `src/constants/uiConst.ts`（rpx 制，rpx(2)≈1pt）；75 个文件经 `useColors()` 消费
- **无底部导航栏**（Stack + 抽屉）→ 迷你播放器用"悬浮圆角卡片"方案
- 首页搜索框已是假输入框（点击跳搜索页）→ 改按钮零逻辑改动
- 播放页次要操作有现成收纳容器：`MusicItemOptions` 面板（支持 `from === MUSIC_DETAIL` 条目显示）
- 播放页已是黑底白字，深色方向下文字无需重配色
- **图标管线**：`src/assets/icons/*.svg`（Heroicons，`fill="currentColor"`）→ `react-native-svg-transformer` → `npm run generate-assets` 按文件名生成 `src/components/base/icon.tsx`（含 `IIconName` 类型）。**保持文件名不变、只换 SVG 内容 = 所有调用点零改动**

**换算基准**：34pt=rpx(68)、22pt=rpx(44)、17pt=rpx(34)、15pt=rpx(30)、12pt=rpx(24)；边距 16pt=rpx(32)；控件圆角 12pt=rpx(24)；卡片圆角 10pt=rpx(20)

## Step 1b：图标统一 Material Design（独立提交）

**方法**：从 `@material-design-icons/svg` 的 **round** 变体（CDN 直链，如 `cdn.jsdelivr.net/npm/@material-design-icons/svg/round/<name>.svg`）下载 SVG，**覆盖写入现有同名文件**（零调用点改动）；后处理：根节点补/换 `fill="currentColor"`（Material 原始文件无 fill 或为 black，必须处理否则 color 属性失效）；最后 `npm run generate-assets` 重新生成 `icon.tsx`。不安装任何 npm 包（仅下载资源文件），无字体文件。
