# 可选的歌曲推荐

本功能在首页加入「猜你喜欢」，使用收藏与最近播放构建本地画像，并查询 Last.fm 的相似歌曲、相似艺人及艺人热门歌曲。它依赖聚合搜索分支提供的版本匹配、来源选择和播放回退接口。

## 配置和数据流

1. 首次打开只显示说明和 API key 输入框；默认关闭，没有内置 key，也不会自动访问推荐服务。
2. 用户填写自己的 Last.fm API key，点击「启用 Last.fm 推荐」后，最多选择 40 首收藏或最近播放歌曲作为种子。
3. 仅向固定的 HTTPS Last.fm API 发送所需歌名、歌手名及请求参数。不发送音频、账户密码、整个歌单对象或设备标识。无需登录或绑定音乐账户；没有自动收藏、听歌记录上传或 scrobbling。
4. 结果排名和去重在本机完成，过滤已收藏歌曲，限制同艺人数量，降低最近听过和特殊版本的优先级。默认不按语言偏好降低某类标题的权重。
5. 页面显示推荐后，通过用户已启用的音乐插件准备对应来源。推荐元数据不是播放源，必须匹配到真实插件条目，不能移植不同提供方的歌曲 ID。
6. 用户可以从页面菜单关闭功能。关闭会删除本机保存的 API key、Last.fm 响应缓存和推荐结果，取消服务请求，并防止迟到响应重新写入已清空的缓存。通用播放器的短时来源缓存由聚合播放模块管理。

API key 保存在应用私有 MMKV 中，没有提供硬件加密或系统钥匙串保护；不会写入源码、日志或 PR。共享设备上的用户应按自己的需要决定是否保存。推荐请求遵守应用的离线及移动网络播放限制。

## 生成、缓存及播放

本地画像采用有限数量的收藏及最近播放记录；对相似单曲不足的种子，使用相似艺人热门曲作为标记明确的回退。排名采用种子权重、候选排名、多种子支持和适度艺人多样性，不使用语言模型生成歌曲。

每批最多 30 首。结果按画像变化和有效期更新，失败时保留有用缓存，部分服务故障不会把已有结果替换成零碎列表。API 并发限制为 3，响应有期限和数量限制，并对限流进行冷却。

提前准备只在推荐页面处于前台时运行，遵守网络设置，与点击播放共享聚合搜索的有界队列。它缓存短期链接与必要请求参数，不预下载整批音频。点击后确认目标版本及真实播放进度，再写入播放历史；失败则尝试同一目标的其他合格来源。

## 复测

- 不填 key：打开「猜你喜欢」，确认只出现说明和配置；不开启推荐网络请求。
- 填写自己的 key 并启用：收藏或播放几首歌，刷新推荐，换批并尝试播放。
- 禁止移动网络播放或断网：确认没有新的 Last.fm 网络请求；已有缓存可保留。
- 请求尚未完成时关闭推荐：确认 key 和推荐服务缓存清空，迟到响应不恢复缓存。
- 保留原来的推荐歌单、榜单、搜索和本地音乐入口。

测试使用虚构歌曲和模拟网络；不需要提交者的 key、账户或私人歌单。Last.fm 对不同语言、艺人和歌曲的覆盖不均，不能保证每位用户都获得足够的新歌曲，也不能保证每个推荐都有可用插件来源。
