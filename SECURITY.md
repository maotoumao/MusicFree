# Security Policy / 安全策略

## Supported Versions / 支持的版本

Only the latest stable release builds are supported with security patches.

## Reporting a Vulnerability / 漏洞汇报

If you identify a security vulnerability (such as a plugin script sandbox escape, local storage file access from untrusted sources, Hermes engine execution flaws, or remote injection in React Native WebViews), please do **not** open a public issue.

Please report vulnerabilities privately by emailing the maintainers or using GitHub's private vulnerability reporting feature.

如果您在系统中发现安全漏洞（如外部插件脚本沙箱逃逸、未授权本地存储文件读取、Hermes 引擎执行缺陷、或 React Native WebView 远程注入等），请勿通过公开 Issue 报告，请使用 GitHub 的私有漏洞报告功能或直接发送电子邮件联系维护者。
