# 多音源聚合搜索

音乐搜索新增「全部音源」结果页，保留原来的各插件独立搜索页。聚合仅使用用户已安装、已启用且支持音乐搜索的插件，不内置音源、下载地址或预设插件评分。

## 使用

1. 安装并启用自己的音乐插件后正常搜索，查看「全部音源」。
2. 在插件设置中，可把插件用于主力搜索、备用搜索，或排除出自动搜索。默认主力使用已启用插件及其现有顺序。
3. 点击「扩大搜索」才加入手动指定的备用插件。
4. 同一歌名、歌手且录音版本和时长兼容的结果合并显示来源数；现场、翻唱、不同年份等存在歧义时保留独立条目。
5. 点击结果后尝试对应真实插件条目；成功起播后记录历史。列表替换仍遵循现有「点击搜索结果」设置。

## 实现与边界

- 聚合与单源音乐搜索共享四并发队列。超时会停止等待，但不可取消的插件调用继续占用槽位直到结束，避免叠加请求突破并发限制。
- 请求标识隔离搜索、分页及快速切换后的迟到结果；每个插件独立维护分页结束状态。
- 基于歌手、标题、版本及已知时长保守匹配；未知元数据无法证明两首音频为同一录音，因此不能保证消除所有重复。
- 用户可明确选择主力、备用、排除。配置绑定插件文件摘要，不根据插件显示名预设可信度。
- 本机成功率和耗时仅用于候选排序，不作为离线测试结论，也不发送到服务器。
- 自动播放使用真实条目、请求头和临时链接；短时链接缓存与长期歌曲身份分离。播放失败会刷新缓存链接或尝试下一候选；不匹配和明显短试听不视为成功。
- 后台准备使用的共享队列和缓存接口供后续可选推荐功能复用，本 PR 不接入推荐服务。

## 验证

运行 `npm test -- --runInBand` 和 `npx tsc --noEmit`。测试覆盖版本去重、身份保持、共享并发、迟到结果、搜索分页、备用扩展、播放回退、短试听、临时链接过期和禁用源。

这些自动化测试使用模拟插件；不将私人设备、私人插件列表或个人评分表作为上游验证证据。欢迎维护者用自己的插件复测搜索及播放行为。
